            6. Plateforme en ligne GitHub Actions
.github/workflows/build-windows.yml		
            GitHub construit tout seul le Setup .exe et le .exe portable dans le nuage et les publie dans Releases et Actions.
            Aucune (0 %)
Pas besoin de Node.js ni de Terminal. Simple double-clic sur le .exe téléchargé.		
            ⭐ N°1 CHOISI & DÉPLOYÉ
Le plus rapide, le plus simple et immédiat.		
          

          

            3. Installateur local
INSTALLER-WINDOWS.bat		
            Double-clic sur INSTALLER-WINDOWS.bat qui lance npm install puis construit le Setup .exe sur le PC.
            Nécessite d'avoir installé Node.js une fois sur le PC constructeur.
            ✅ Inclus dans le dépôt (prêt si vous voulez reconstruire sur PC).
          

          

            4. Essai direct
LANCER.bat		
            Double-clic sur LANCER.bat (fait npm install la 1re fois puis ouvre le logiciel).
            Nécessite Node.js sur le PC.
            ✅ Inclus dans le dépôt.
          

          

            5. Mode secours
LANCER-MODE-SECOURS.bat		
            Lance le logiciel avec --mode-secours --disable-gpu si la transparence clignote sur une ancienne carte graphique.
            Simple double-clic.
            ✅ Inclus dans le dépôt + bouton testable ici en direct.
          

          

            7. Terminal
npm install puis npm run dist		
            Taper les commandes manuellement dans l'Invite de commandes Windows.
            Connaissance du Terminal requise.
            Remplacé avantageusement par les Moyens 6 (auto) et 3 (double-clic).
